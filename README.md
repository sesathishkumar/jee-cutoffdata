# JEE 2026 branch-wise cutoffs

[Download the Excel workbook](./JEE_2026_Branch_Wise_Cutoffs.xlsx)

The workbook contains 12,936 opening and closing rank records for all 138 institutes in JoSAA 2026 Round 5. Filter the branch cutoffs by institute, programme, category, quota, and gender pool.

It includes JEE Main qualifying percentiles, JEE Advanced qualifying marks, and Advanced marks ranges where the published rank-to-marks data supports them.

Sources: [JoSAA opening and closing ranks](https://josaa.nic.in/or-cr/), [NTA JEE Main 2026 results](https://www.nta.ac.in/Download/Notice/Notice_20260420194021.pdf), and [JEE Advanced 2026 report](https://jeeadv.ac.in/reports/2026.pdf).
